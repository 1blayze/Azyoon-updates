## Sobre o Azyoon

O **Azyoon** é uma plataforma de comunicação criada para aproximar amigos e comunidades.

Converse por mensagens, participe de chamadas de voz e vídeo, compartilhe sua tela e acompanhe seus amigos enquanto joga — tudo em um só lugar.

## Sobre este repositório

Este é o repositório oficial de distribuição do **Azyoon**.

Aqui são publicadas as versões do aplicativo para Windows e os arquivos necessários para manter o Azyoon atualizado.

O desenvolvimento principal do produto é mantido separadamente deste repositório de distribuição.

---

## Atualizações

O Azyoon possui um sistema integrado de atualizações.

Quando uma nova versão está disponível, o aplicativo pode detectar e instalar a atualização, permitindo que você receba:

- novos recursos;
- melhorias de desempenho;
- correções de problemas;
- melhorias de estabilidade;
- aprimoramentos de segurança;
- refinamentos na experiência do usuário.

Recomendamos manter o Azyoon sempre atualizado.

---

## Versões experimentais

Algumas versões podem ser disponibilizadas exclusivamente para testes.

Essas builds podem incluir funcionalidades ainda em desenvolvimento e apresentar comportamento diferente ou menor estabilidade.

Para uso normal, prefira sempre a versão estável mais recente.
