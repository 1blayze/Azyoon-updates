# Azyoon

**Converse, jogue e fique perto de quem importa.**

O **Azyoon** é uma plataforma de comunicação para amigos e comunidades.

Troque mensagens, participe de chamadas de voz e vídeo, compartilhe sua tela e acompanhe seus amigos enquanto joga — tudo em um só lugar.

### Azyoon para Windows

## Sobre este repositório

Este é o repositório oficial de distribuição do **Azyoon**.

Aqui são publicadas as versões oficiais do aplicativo para Windows e os arquivos necessários para manter o Azyoon atualizado.

Para uso normal, recomendamos sempre baixar a versão marcada como **Latest** na página de Releases.

## Atualizações

O Azyoon possui atualizações integradas.

Quando uma nova versão está disponível, o aplicativo pode detectar e instalar a atualização automaticamente, mantendo você sempre na versão mais recente.

## Versões experimentais

Algumas versões podem ser disponibilizadas exclusivamente para testes.

Essas builds podem conter recursos ainda em desenvolvimento e apresentar menor estabilidade.

Para uso diário, prefira sempre a versão estável mais recente.
